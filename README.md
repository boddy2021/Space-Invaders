# Space-Invaders  
A game I made using C# and Visual Studio. It has 10 levels that get progressively harder and a login system. I built this game in 10th grade to learn C#, SQL, and Windows Forms.

**Features**  
- 10 levels of difficulty  
- Local login system  
- Simple interface  

**How to run it**  
- Just open the _Game.exe_ file  

**Controls & Gameplay**  
- Move left and right using the ← → arrow keys  
- Shoot by pressing Space  
- After winning a level, you progress to the next one  
- The last completed level is saved in the database
